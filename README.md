## 👋 About

**Web / Minecraft** を軸に、Windows 向けのデスクトップアプリも個人開発しています。
作ったものは **MIT ライセンスで公開**し、インストーラ付きで誰でもすぐ使えるように配布しています。
開発では **Claude Code** と **Antigravity** を使って、素早く作って素早く直すサイクルを回しています。
